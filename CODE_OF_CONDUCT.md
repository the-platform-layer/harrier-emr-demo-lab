# Code Of Conduct

Be respectful, practical, and careful with other people’s AWS environments.

## Expected Behavior

- Keep feedback focused on evidence and safety.
- Treat logs, account IDs, and generated reports as potentially sensitive.
- Prefer safer demo paths when a scenario can be simulated.
- Help new contributors avoid cost and cleanup surprises.

## Unacceptable Behavior

- Harassment or discriminatory language.
- Publishing credentials, private logs, or account-specific details.
- Encouraging unsafe resource creation without cleanup guidance.
- Repeated off-topic comments that make collaboration harder.

Maintainers may remove content or restrict participation when needed.
