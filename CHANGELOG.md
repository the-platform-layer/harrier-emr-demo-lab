# Changelog

All notable changes to Harrier EMR Demo Lab will be documented here.

This project uses semantic versioning for documented public milestones. Demo
lab releases do not publish runtime artifacts or deploy AWS resources.

## v0.1.0 - 2026-06-04

- Added open-source governance files and contributor guidance.
- Added product-facing demo README structure.
- Added GitHub issue and pull request templates.
- Added label sync automation for public issue triage.
- Added release workflow scaffolding for documented demo-lab milestones.
- Added repository hygiene checks to block tracked local state, generated output, and caches.
- Added a public release checklist and removed internal slice wording from scenario docs.
- Standardized Apache-2.0 license text for GitHub license detection.
